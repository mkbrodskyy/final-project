## About the Project

News Explorer is a React application that allows users to search for news articles by keyword, view results, and save articles to their profile. The project is built according to a detailed Figma design and follows modern frontend best practices.

## Features

- Search for news articles by keyword using the News API
- Responsive, accessible UI based on Figma design
- Save and view favorite articles (protected route)
- Modal windows for login, registration, and feedback
- Preloader animation while fetching news
- About section with author information
